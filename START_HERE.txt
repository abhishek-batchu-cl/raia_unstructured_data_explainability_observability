🎯 TYPICAL WORKFLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Start Services
     └─ ./quickstart.sh  OR  docker-compose up

  2. Integrate SDK
     └─ Add 5 lines to your agent code:
        from raia import EventEmitter, EmitterConfig
        emitter = EventEmitter(config)
        emitter.emit({"event": "session_start", ...})

  3. Run Your Agent
     └─ Events automatically collected & validated

  4. View Metrics
     └─ python tools/replay_compute.py events.ndjson

  5. Set Alerts
     └─ kubectl apply -f observability/prometheus_alerts.yaml
