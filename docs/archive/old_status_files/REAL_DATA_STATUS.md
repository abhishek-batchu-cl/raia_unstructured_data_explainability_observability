# RAIA Platform - Real Data Status

## ✅ What's Working (REAL Computed Data)

### 1. RAG Evaluation Metrics
**Source**: demos/01_complete_demo.py - Actual RAG pipeline with vector embeddings

- **10 retrieval metrics** - Real queries evaluated against knowledge base
  - Precision @ K: 100% (computed from retrieval results)
  - Recall @ K: 100% (computed from relevance judgments)
  - MRR, NDCG: Computed from ranking
  
- **10 answer quality metrics** - Real answers evaluated
  - Faithfulness: 76.7% average (computed from attribution)
  - Hallucination: 23.3% average (computed detection)
  - Answer relevance, completeness, conciseness: Computed

### 2. Explainability Data (RAIA Explainability)
**Available in database** - Not yet exposed in UI

- **5 attribution maps** - Maps answer spans to source documents
  - Example: "Reset password if" → doc_login_issues (confidence: 29.4%)
  - Shows exact character spans and similarity scores
  
- **5 reasoning traces** - Step-by-step RAG process
  - Query Analysis: Extracted key terms
  - Document Retrieval: Retrieved docs with similarity scores
  - Answer Synthesis: How answer was constructed
  - Each step has latency, inputs, outputs, rationale

### 3. Real Query Examples
From actual Customer Support AI scenario:
- "How do I reset my password?"
- "What payment methods do you accept?"
- "Can I integrate with Slack?"
- "Is my data encrypted?"
- "Do you have a mobile app?"

All answers generated by RAG pipeline, not hardcoded!
